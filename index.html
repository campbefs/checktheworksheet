What the Worksheet does that its text doesn't say

Four findings, each pinned to the form's own calculation scripts.

Verified against the form's own scripts → live tool above

The hardship test reads a different income than the order pays from

Line 7e computes hardship on gross-derived income; the order is paid from net.

57% of net income, the moment Line 7e itself still reads 40%

Verified against the form's own scripts

Child care is split on income the order has already changed

Line 3c allocates child care on income shares fixed before base support moves money.

88¢ of every child care dollar, funded by the payor

Verified against the form's own scripts

The credit for equal parenting time contains no parenting-time term

Line 6g nets the parents' Line 6e amounts; no count of overnights enters at any point.
